# Rock 'n' Roller III: World Tour

The third [Rock 'n' Roller](https://github.com/h1ddenpr0cess20/rocknroller).
Rock, the boulder, takes the band on a world tour, and rolls through ten
stops on the way to each night's show: London, Paris, Venice, the Alps,
Spain, Egypt, Tokyo, Rio, Sydney and New York. It runs on the engine of
[Rock 'n' Roller II: Hollywood Nights](https://github.com/h1ddenpr0cess20/rocknroller-ii).

Work in progress.

## Run

```sh
npm install
npm run dev               # → http://localhost:5173
```

A static page: no server, no keys. `npm run build` puts it in `dist/`. WebGPU
where the browser has it, WebGL2 otherwise. Node 22.12 or later.
